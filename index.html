Sobre esta demo

Um repositório pequeno para praticar o fluxo de trabalho em equipa: branches, pull requests, revisões, issues e publicação automática.

O que vamos praticar

1. Branch

Cada alteração nasce numa branch própria, sem tocar na main.

2. Pull request

Propomos a alteração, explicamos o porquê e pedimos revisão.

3. Revisão e merge

Outra pessoa aprova. Só depois a alteração entra na main.

4. Issue

Registamos melhorias e fechamo-las com um PR que diz "Closes #".
